# Stack tecnológica

## Frontend

| Tecnologia         | Uso                                                          |
| ------------------ | ------------------------------------------------------------ |
| HTML5 semântico    | Páginas, formulários, tabelas, diálogos e navegação.         |
| CSS responsivo     | Tokens, componentes, foco, movimento reduzido e breakpoints. |
| JavaScript ES2020+ | Interações, dados, validação e gateway.                      |
| Material Symbols   | Família única de ícones.                                     |
| Google Fonts       | Poppins para títulos e Inter para conteúdo.                  |
| Chart.js           | Gráficos acadêmicos que exigem escalas e tooltips.           |

O frontend permanece estático e sem bundler. Isso reduz a barreira de execução e permite hospedar o projeto em qualquer servidor de arquivos.

## Backend como serviço

| Tecnologia         | Uso                                       |
| ------------------ | ----------------------------------------- |
| Supabase Auth      | Sessões, cadastro e autenticação.         |
| PostgreSQL         | Persistência relacional.                  |
| PostgREST          | API gerada a partir de tabelas e funções. |
| Row Level Security | Autorização por usuário, papel e turma.   |
| Funções RPC        | Operações transacionais da biblioteca.    |

## Ferramentas locais

- Node.js para scripts administrativos.
- supabase-js para seed e cliente do navegador.
- dotenv para variáveis locais.
- Servidor HTTP estático para desenvolvimento e QA.

## Compatibilidade

- Navegadores modernos com dialog, Grid e Flexbox.
- Leitura de código de barras depende de BarcodeDetector e deve ter alternativa manual.
