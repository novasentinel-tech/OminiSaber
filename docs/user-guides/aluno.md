# Guia do aluno

## Objetivo

Orientar o uso das áreas de aprendizagem do OminiSaber.

## Estrutura

O aluno acessa Início, Trilhas, Redação, Evolução, Biblioteca, Agenda, Notificações e Perfil em `frontend/aluno/`.

## Funcionamento

Entre com a conta fornecida pela escola. Trilhas e atividades publicadas aparecem conforme turma e matéria. Redações podem ser planejadas, revisadas e enviadas; resultados e progresso são calculados a partir de registros reais.

## Pontos de atenção

Quando não houver conteúdo, a tela exibe estado vazio. Consulte [módulo do aluno](../modules/aluno/README.md) para contratos técnicos.
