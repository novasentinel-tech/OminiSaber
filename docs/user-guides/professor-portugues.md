# Guia do professor de Português

## Objetivo

Orientar a operação de linguagem, avaliações e redações.

## Funcionamento

Use a Visão geral para acompanhar turmas e pendências, a Oficina para criar conteúdo, Avaliações para montar instrumentos e Redações para ler submissões e publicar devolutivas.

## Banco de dados

As ações usam propostas, redações, competências, comentários, rascunhos e avaliações vinculados ao professor e às suas turmas.

## Pontos de atenção

Uma conta precisa ter `role = professor`, `tipo_professor = portugues` e vínculos
ativos em `professor_turma_materias`. O vínculo legado em `professor_turmas` não é
suficiente, isoladamente, para autorizar uma nova atividade.
