## meu dia

Use case: ui-mockup. Create one realistic, production-quality desktop teacher dashboard UI design, with clear hierarchy, strong typography, intentional spacing. Concept name: "Meu dia".
Target dimensions: 1440 x 1024, landscape desktop web app, flat front-on screenshot of the UI only, no device, no perspective, no browser chrome, no collage, no external option number.
Input references: Image 1 is OUR current OminiSaber teacher dashboard; preserve its recognizable royal-blue and white product design language while redesigning information hierarchy. Image 2 is the Letrus dashboard, a comparator only: learn from visible navigation labels and focus on student progress. Do not copy their branding, large character, tiny graph, or large empty cards.
Goal: a Portuguese-speaking school teacher should immediately understand what requires attention today, and take the next useful action. This is a concept for an existing product, not a marketing page.
Brand "OminiSaber"; tools named "OminiStudio" and "Copiloto". Royal blue #1557EF, white, extremely pale blue background, near-black navy text, muted blue-grey supporting text. Inter-style typography, body 15–16px, clear 30px heading. Outline icons with text labels, subtle rounding 12–16px, sparing borders and shadows. Blue is reserved for selected nav and a single main action. No gradients dominating the page, no mascot, no emoji.
Expanded sidebar approximately 220px: product brand at top; "Visão geral" selected; "Turmas", "Atividades", "Trilhas", "OminiStudio", "Agenda". At bottom "Ajuda" and "Meu perfil". All readable icons AND labels.
Main header, compact: "Seu dia, com clareza." / "Veja o que precisa da sua atenção." Small date "4 de outubro de 2026" and small outline action "Criar atividade". Current date anchor 2026-10-04. Do not use inconsistent dates.
A compact summary line rather than four large metric cards: "4 turmas · 112 alunos · 3 atividades em andamento".
Main area about 2/3 width: an integrated work queue headed "Precisa da sua atenção", two clean rows with divider:
"12 respostas para corrigir" with detail "Argumentação e leitura crítica" and prominent blue primary CTA "Revisar respostas".
"8 alunos precisam de apoio" with detail "Dificuldade em identificar a ideia principal" and a quieter text action "Ver alunos".
Right approximately 1/3 width: compact upcoming activity section "Próxima entrega"; "Leitura crítica"; "1º ano B"; "Entrega em 6 de outubro"; progress bar and "24 de 28 entregas"; quiet link "Acompanhar".
Below these, one wide well-sized trend chart section "Evolução das turmas" with a single clear royal-blue line, y-axis 0, 25, 50, 75, 100%; x-axis 1 set, 8 set, 15 set, 22 set, 29 set, 4 out. Values roughly 66,68,72,75,77,80. Label metric explicitly "Percentual de entregas" so not confusing it with learning achievement. Show latest "80% das atividades entregues", and subtle text "90 de 112 entregas". Make chart actually readable, not decorative.
At bottom one discreet text row "Quer preparar uma recuperação? Peça ideias ao Copiloto" with a small outline sparkle icon and link "Pedir ideias". No floating orb, no full chatbot, no gigantic OminiStudio advertisement. Tiny visible footer "Dados demonstrativos".
Keep few sections and generous usable whitespace, but no huge empty panels. Prefer typography, alignment, spacing and row separators over card nesting. A focused primary screen, not a feature inventory. No invented extra widgets, scores, badges, tabs, filters or student ranking. Entire dashboard cleanly fits the 1440x1024 frame, complete unclipped content, readable and accurate Portuguese spelling. One independent image only.

## minhas turmas

Use case: ui-mockup. Create one realistic, production-quality desktop teacher dashboard UI design, with clear hierarchy, strong typography and purposeful spacing. Concept name: "Minhas turmas".
Target dimensions: 1440 x 1024 landscape desktop web application, flat front-on UI screenshot only. No browser chrome, device frame, perspective, numbered label, or collage.
Input references: Image 1 is OUR current OminiSaber dashboard: keep recognizable royal-blue/white brand and modern typography but improve usability. Image 2 is Letrus, used only for the idea of clear navigation and teaching progress, never its branding or oversized illustration.
Goal: teacher immediately sees how each class is doing and identifies the class needing intervention. This is a strong class-centered alternative to a daily work queue. Product name "OminiSaber", creator "OminiStudio", assistant "Copiloto". Portuguese Brazilian text. Royal blue #1557EF, near-black navy text, white surface, very pale blue background, subtle green and amber status icons WITH descriptive labels. Inter-like typography 15–16px body, 30px headings. Outline icons AND navigation labels. 12–16px corners, thin borders only where needed, minimal shadows, no decorative gradient or mascot.
Approximately 220px full-height sidebar: "OminiSaber", "Visão geral" selected, "Turmas", "Atividades", "Trilhas", "OminiStudio", "Agenda"; bottom "Ajuda", "Meu perfil".
Header "Como estão suas turmas?" and subtitle "Encontre quem precisa de apoio e acompanhe as entregas." A small outline action "Criar atividade". Current date anchor 2026-10-04. Header date "4 de outubro de 2026".
Under heading a simple in-line summary "4 turmas · 112 alunos · 3 atividades em andamento", not a row of giant cards.
Main composition: broad left class table/list taking 75% width, narrow right action column. Clean spacious readable table heading "Acompanhamento das turmas". Columns "Turma", "Entregas", "Precisam de apoio", "Ação". Each of four rows roughly 105px high with dividers, class name bold and activity subtitle, labeled bar for delivery percentage, students needing support with words not just colors, and discrete action.
Rows:
"1º ano A" / "Leitura crítica"; "19 de 28 · 68%"; "3 alunos"; quiet "Acompanhar".
"1º ano B" / "Argumentação"; "24 de 28 · 86%"; "4 alunos"; this row has subtle pale amber attention indicator "Prioridade de apoio" and one main royal-blue CTA "Acompanhar turma".
"2º ano A" / "Produção de texto"; "21 de 28 · 75%"; "1 aluno"; quiet "Acompanhar".
"2º ano B" / "Leitura e interpretação"; "26 de 28 · 93%"; "Nenhum aluno"; quiet "Acompanhar".
Do not invent four activities: these are class learning topics; header independently has three ongoing activities. Support totals exactly 8 students; delivery totals 90/112, roughly80%. Show footer of table "90 de 112 entregas · 80% no período". Delivery progress is not a mastery grade.
Right narrow column "Sua próxima ação"; compact summary "12 respostas aguardam correção" with quiet action "Revisar respostas". Below it short helpful context "Apoio em leitura" and "8 alunos precisam de uma nova oportunidade de prática." Small outline/text action "Planejar com o Copiloto". No full chat or multiple equally dominant buttons.
Below main table, a wide light grouped section "Trilhas em andamento" with exactly three horizontal compact items in a single grouped row, not nested big cards. Topics "Leitura crítica", "Argumentação", "Produção de texto"; each has a simple understated progress bar and quiet link "Ver trilha". No random extra metrics.
Tiny footer "Dados demonstrativos". Design a focused primary screen, not a feature inventory. Use strong alignment, generous spacing, row separators before borders and shadows. No mascot, no giant banner, no floating assistant bubble, no tiny unreadable charts, no student ranking. Entire composition fits cleanly inside1440x1024, legible correct Portuguese labels, complete unclipped screen. One independent image only.
