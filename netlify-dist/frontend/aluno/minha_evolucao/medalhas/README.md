# Medalhas individuais

Cada página desta pasta apresenta a biografia, o requisito e a recompensa de uma conquista padrão. As identidades usam classes próprias para que a galeria possa evoluir sem transformar todas as medalhas em um card genérico.

As páginas são peças editoriais de referência; o estado oficial de desbloqueio continua sendo calculado em `../medalhas.js` com `conquistas_aluno`.
