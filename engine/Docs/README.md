# Documentação do OminiStudio

## Objetivo desta fase

Validar a experiência de criação antes de conectá-la ao banco de dados e às telas reais do aluno. O protótipo já permite montar, reorganizar, testar e revisar uma atividade interativa.

## O que está pronto

- tela inicial de escolha entre os dois modos de criação;
- cartões interativos com inclinação 3D e suporte a teclado;
- Mesa de Montagem com biblioteca de blocos, sequência e propriedades;
- Mapa da Experiência com nós, conexões, zoom, arraste e minimapa;
- blocos de conteúdo, número, múltipla escolha, resposta aberta, condição e Flourish;
- ramificações de fluxo por respostas e condições;
- simulação completa da experiência do aluno;
- validação antes da revisão;
- exportação do projeto em JSON;
- salvamento local automático no navegador;
- layouts específicos para desktop, tablet e celular.

## Status

Esta é uma versão **alfa funcional de UX**. Ainda não publica atividades para turmas reais nem registra notas no banco. Essas integrações pertencem à próxima fase.
